# Edu Motivation Platform

MVP-платформа мотивации учеников и студентов через задания, баллы, рейтинг, достижения и награды.

## Что умеет сайт

- регистрация и вход;
- роли: ученик/студент, учитель/организатор, администратор;
- личный кабинет ученика;
- кабинет учителя;
- админ-панель;
- публикация заданий и проектов;
- загрузка ответа, отчёта, фото, видео или файла;
- проверка выполненных работ;
- начисление баллов;
- рейтинг участников;
- достижения и значки;
- награды, партнёры и обмен баллов;
- уведомления;
- базовая поддержка русского и кыргызского языка в интерфейсе;
- адаптивный дизайн под телефон.

## Требования

- Node.js 18 или выше.
- Дополнительные npm-пакеты не нужны.

## Запуск локально

```bash
cd edu-motivation-platform-v4
npm start
```

Открой в браузере:

```text
http://localhost:3000
```

## Где хранятся данные

Данные хранятся в файле:

```text
data/school.json
```

Загруженные учениками файлы хранятся в папке:

```text
uploads/
```

Для сброса демо-данных:

```bash
npm run reset:data
npm start
```

## Роли

### Ученик / студент

- видит задания;
- отправляет отчёт или файл;
- получает баллы после проверки;
- видит рейтинг;
- видит свои достижения;
- обменивает баллы на награды.

### Учитель / организатор

- создаёт задания;
- публикует задания;
- проверяет работы учеников;
- начисляет или отклоняет баллы;
- видит статистику и рейтинг.

### Администратор

- видит общую аналитику;
- управляет пользователями;
- блокирует пользователей;
- добавляет партнёров;
- добавляет награды;
- управляет системой поощрений.

## Как захостить на VPS

1. Купить или подготовить VPS с Ubuntu.
2. Установить Node.js 18+.
3. Загрузить проект на сервер.
4. Запустить:

```bash
npm start
```

5. Для постоянной работы лучше использовать PM2:

```bash
npm install -g pm2
pm2 start server.js --name edu-platform
pm2 save
pm2 startup
```

6. Подключить домен через Nginx reverse proxy.
7. Выпустить SSL-сертификат через Let's Encrypt.

Пример Nginx-конфига:

```nginx
server {
    server_name your-domain.com www.your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## Важно для реального запуска

Эта версия — рабочий MVP. Для большого количества пользователей лучше перейти с JSON-файла на PostgreSQL/MySQL, добавить восстановление пароля, подтверждение email, резервное копирование и полноценное хранение файлов в S3/облачном хранилище.


## Обновление v5

Исправлено обновление кабинета учителя после отправки работы учеником.
Теперь:

- в кабинете учителя появилась кнопка **Обновить**;
- кабинет проверки автоматически обновляется каждые 7 секунд;
- учитель/организатор видит отправленные работы на проверку сразу после обновления страницы или автообновления;
- учитель может проверять работы, даже если задание создал другой организатор или администратор.
